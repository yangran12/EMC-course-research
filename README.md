# 电磁兼容课程小组调研

本项目研究开关电源 EMI 滤波器小型化与压电谐振抑制技术。课程要求为文献调研和课堂汇报，由一人主讲，小组成员共同准备资料。

研究重点是压电器件如何通过选频谐振帮助抑制共模传导干扰，以及这种方案在体积、损耗和适用条件上的取舍。以传统无源滤波为比较基准，主动滤波作为补充背景。

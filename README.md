# 电磁兼容课程小组调研

本项目当前选题为“电源线上的‘小鼓包’有什么用？——磁环抑制电磁干扰的原理与应用”。课程要求为文献调研和课堂汇报，由一人主讲，小组成员共同准备资料。

本次以二线直流供电为贯穿例子，先解释正常往返电流与共模分量，再讨论磁环的频率响应、穿线次数和安装方式，用村田公开的加磁环前后辐射测试案例分析效果。理论控制在基础电路和磁化方向的层面，原压电主题资料保留作历史准备材料。
